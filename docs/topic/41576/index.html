    NIKKEI TECH

    ソウル市が聖水大橋南端の進入ランプにある段差を2013年に初めて把握していたことが分かった。当時の段差は約80ミリで、その後2016年までに最大9ミリ程度、さらに沈下していた。特に、段差が初めて確認され、その後も沈下が続いた時期の安全点検で、段差は別途管理対象に含まれていなかった。ソウル市の安全管理体制やその後の対応が適切だったのかを巡り、指摘が出ている。...
