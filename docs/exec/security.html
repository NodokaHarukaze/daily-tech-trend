1. ChatGPT、Macの操作を記憶する「コンピュータ履歴」機能の提供開始

何が起きているか
OpenAIがmacOS版ChatGPTデスクトップアプリに「Computer History」機能を追加し、ユーザーの操作履歴を記憶・参照できるようにした。
事業への影響
企業の情報漏洩リスクが増大し、従業員の業務データが外部AIサービスに蓄積されることで、コンプライアンス違反や機密情報流出の懸念が高まる。
推奨行動
経営層は社内でAIツール利用ポリシーを策定・周知し、データ保持・アクセス権限の管理体制を強化する。また、必要に応じて社内専用AI環境の導入を検討する。

2. MetabaseのSQLインジェクション脆弱性（CVE-2026-72898）に関する注意喚起

何が起きているか
Metabaseの最新版にSQLインジェクション脆弱性が報告され、攻撃者が任意のSQLを実行できる可能性があるとJPCERT/CCが警告した。
事業への影響
社内でMetabaseをBIツールとして利用している企業は、データベースへの不正アクセスや情報漏洩、業務停止リスクが高まる。
推奨行動
経営層は即時にMetabaseのパッチ適用状況を確認し、未適用の場合は直ちにアップデートを実施する。さらに、アクセス制御・監査ログの整備を行い、脆弱性対策の継続的な監視体制を構築する。

3. CISAが発表したICS・医療機器の複数脆弱性（複数製品）

何が起きているか
米国CISAが、Siemens、Johnson Controls、ANDRITZなどの産業制御システム・医療機器に対する複数の脆弱性を公開し、リモートコード実行や権限昇格、情報漏洩のリスクを指摘した。
事業への影響
製造業・医療機関など、ICSや医療機器を使用する企業は、システム停止・データ漏洩・サービス妨害の重大リスクに直面し、事業継続計画や顧客信頼に大きな影響を与える。
推奨行動
経営層は対象製品の脆弱性評価を実施し、CISAが推奨するパッチ・アップデートを速やかに適用する。加えて、ICS・医療機器のセキュリティ監視体制を強化し、定期的な脆弱性スキャンとインシデント対応訓練を実施する。
