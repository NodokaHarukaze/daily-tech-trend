1. Meta、セルフィー動画で本人確認を実施する「Facebook Verified」を導入

何が起きているか
Metaは自撮り動画を用いた本人確認バッジを無料で提供し、ユーザーが実在する人物であることを証明できる仕組みを開始した。
事業への影響
ユーザーの信頼性向上と偽アカウント対策が進む一方、認証プロセスの導入コストやプライバシー懸念が企業側の運用負担になる。
推奨行動
経営層は、社内SNSや顧客向けコミュニケーションツールでの本人確認基準を見直し、必要に応じてセルフィー認証を導入することでブランド信頼性を高める。また、データ保護方針を更新し、ユーザー同意取得プロセスを整備する。

2. Google、ログイン時にセルフィー動画を追加認証手段として採用

何が起きているか
Googleはアカウントへのログイン時にセルフィー動画を利用した本人確認機能を追加し、通常のログイン手段が使えない場合の代替手段として提供した。
事業への影響
多要素認証の強化によりアカウント乗っ取りリスクが低減するが、ユーザーのログイン体験が複雑化し、サポートコストが増加する可能性がある。
推奨行動
経営層は、社内システムや顧客向けサービスでの多要素認証設計を再検討し、セルフィー認証を含む柔軟な認証フローを構築する。加えて、ユーザー教育とサポート体制を強化し、認証失敗時のリカバリプロセスを整備する。
