1. Metabase SQLインジェクション脆弱性（CVE-2026-72898）

何が起きているか
MetabaseのSQLインジェクション脆弱性が公開され、攻撃者がデータベースに不正アクセスできる可能性がある。
事業への影響
社内外のデータベースに対する機密情報漏洩リスクが急増。顧客データや業務情報が外部に流出し、信頼失墜・法的制裁の可能性がある。
推奨行動
既定のパッチ適用を直ちに実施し、脆弱性スキャンを定期的に実行。社内の開発・運用チームに対し、SQLインジェクション対策の教育を徹底。

2. OpenAI Ultrafastモード（GPT-5.6 Sol）の高速化

何が起きているか
OpenAIが標準処理より最大14倍高速に動作するUltrafastモードを限定プレビューで提供開始。
事業への影響
AIベースのサービスや業務自動化の応答速度が大幅に向上し、顧客体験の改善・競争優位性の獲得が期待できる。
推奨行動
社内でUltrafastモードを試験導入し、APIコスト・性能を評価。必要に応じて既存AIワークフローをアップグレードし、顧客向けサービスに反映。

3. CISAICSに関する複数の産業制御システム脆弱性（Siemens, Johnson Controls等）

何が起きているか
複数のICS製品（Siemens Desigo DXR、PXCコントローラー、Johnson Controlsエアウォール等）がリモートコード実行・DoS等の脆弱性を有し、CISAが警告を発表。
事業への影響
工場・インフラ運用に不可欠な制御システムが攻撃対象となり、稼働停止・安全リスク・事業継続障害が発生する恐れがある。
推奨行動
対象製品のパッチ適用状況を確認し、速やかに更新。ICS環境の脆弱性スキャンを定期実施し、侵入検知・防御策を強化。経営層はリスク管理体制を見直し、サプライヤーとの連携を強化。
