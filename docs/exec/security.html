1. NTTドコモが名古屋で無料自動運転タクシー実証を開始

何が起きているか

事業への影響
自動運転技術の実用化に向けた市場の加速と、モビリティサービス事業の競争環境が変化。既存のタクシー・物流企業はサービス差別化とコスト構造の見直しが求められる。
推奨行動
経営層は自社のモビリティ・サービス戦略を再評価し、パートナーシップや技術投資計画を策定。顧客体験向上と安全性確保のためのリスク管理体制を整備する。

2. NECが社内全てをAIで運用する新組織「コーポレートAI・Workforce部門」を設立

何が起きているか
部門長から社員までAIが業務を担い、人間は評価・意思決定を行う体制を導入。
事業への影響
組織運営の自動化・効率化が進み、人的リソースの再配置やスキルシフトが必要になる。AI導入に伴うガバナンス・倫理リスクも増大。
推奨行動
経営層はAI導入ガイドラインとガバナンス体制を整備し、従業員教育・スキルアップ計画を策定。AI活用のROIを定期的に評価し、組織文化への影響をモニタリングする。

推奨行動
経営層はリスクアセスメントを実施し、脆弱性修正とパッチ管理の優先順位を決定。サイバーインシデント対応計画を更新し、従業員向けのセキュリティ教育を強化する。
