何が起きているか

事業への影響

推奨行動
①既存ICS・医療機器の脆弱性スキャンを実施し、CISA勧告に該当する項目を優先的に修正。②社内セキュリティポリシーを更新し、定期的なパッチ管理と監視体制を強化。③外部専門家と連携し、脆弱性対応計画を策定・実行。

何が起きているか

推奨行動
