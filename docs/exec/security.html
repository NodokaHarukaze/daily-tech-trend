1. CISA、上下水道システム部門に対し、PLCを標的とした活動からOTを守るよう要請

何が起きているか
水道・下水処理施設のPLC（プログラマブルロジックコントローラ）がサイバー攻撃の主要標的となり、CISAがOT（運用技術）保護を強化するよう要請した。
事業への影響
既存のPLCを使用している水道事業者は、脆弱性を突かれシステム停止やデータ改ざんが発生し、サービス停止や環境汚染、法的責任・罰金のリスクが増大する。
推奨行動
①既存PLCの脆弱性評価を実施し、パッチ適用・ファームウェア更新を優先的に行う。②ネットワーク分離・ファイアウォール設定を強化し、外部からのアクセスを制限する。③SOC（セキュリティ運用センター）と連携し、異常検知ルールを更新し、定期的に侵入テストを実施する。

2. Microsoftが進む本物の成果を生むAI

何が起きているか
MicrosoftがAI開発の効率化と実用化を推進し、コード量を削減しつつ実績を出す新しいAI開発手法を発表した。
事業への影響
企業がAIプロジェクトを高速化できる一方、既存の開発プロセスやツールチェーンが大きく変わり、スキルギャップやツール投資の再検討が必要になる。
推奨行動
①社内AI開発チームに対し、新しいAI開発フレームワークとベストプラクティスの研修を実施する。②既存プロジェクトでAIを導入する際は、Microsoftの推奨ツールを試験導入し、コスト・リスクを評価する。③AIプロジェクトのガバナンス体制を整備し、倫理・コンプライアンスリスクを管理する。

3. Open source software: Security Principles and Practices guidance

何が起きているか
CISAがオープンソースソフトウェア（OSS）のセキュリティ原則と実践に関する新しいガイダンスを公開した。
事業への影響
OSSを多用する企業は、脆弱性管理・更新プロセスが不十分だと、サプライチェーン攻撃や不正コードの混入リスクが高まり、製品品質・顧客信頼に直結する。
推奨行動
①社内OSS使用ポリシーを策定し、ライセンス・脆弱性情報の追跡を自動化する。②OSSコンポーネントの定期的なスキャンとパッチ適用をCI/CDパイプラインに組み込み、リリース前に検証を徹底する。③サプライチェーンリスク管理体制を強化し、外部パートナーに対しても同等のセキュリティ基準を適用する。
