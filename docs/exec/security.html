1. CISAが発表したICS・医療機器向け脆弱性アドバイザリ（複数）

何が起きているか
米国CISAがICS（産業制御システム）と医療機器に対する複数の脆弱性を公開し、攻撃者が遠隔操作でシステムを乗っ取る可能性を示した。
事業への影響
製造業・医療機関が使用する制御システムや医療機器の安全性が脅かされ、サービス停止・データ漏洩・法規制違反のリスクが増大。特に日本国内の工場や病院で導入されている製品は即時のパッチ適用が求められる。
推奨行動
① 既存のICS・医療機器の構成を棚卸し、CISAアドバイザリに該当する製品を特定。② 速やかにベンダーからのパッチを適用し、テスト環境で検証後本番へ展開。③ パッチ適用後の監視体制を強化し、異常検知を自動化。④ 取引先・顧客へリスク共有と対策状況を報告し、信頼維持に努める。

2. Gunra Ransomware-as-a-Service（RaaS）の台頭

何が起きているか
GunraというRaaSが拡散し、政府機関や大企業を狙うランサムウェア攻撃が増加している。
事業への影響
企業ネットワークが侵害されると、業務停止・機密情報漏洩・金銭的損失が発生。特に金融・製造・医療分野では被害が深刻化し、ブランドイメージの低下や規制罰則のリスクも高まる。
推奨行動
① エンドポイント保護を最新化し、ゼロデイ対策を実装。② ネットワーク分離・アクセス制御を徹底し、内部からの横移動を防止。③ 重要データは定期的にオフラインバックアップし、復旧計画を策定。④ 社内外のセキュリティ教育を強化し、フィッシングや不審メールへの警戒を徹底。

3. Siemens製品の重要アップデート（2026年8月）

何が起きているか
Siemensが複数の産業機器に対し、重大脆弱性を修正するアップデートを公開。
事業への影響
Siemens製品を使用する工場・インフラ事業者は、旧バージョンのままでは外部攻撃に対して脆弱であり、業務停止や生産ラインの停止リスクがある。
推奨行動
① 既存Siemens機器のバージョンを確認し、該当アップデートを適用。② アップデート後の機能テストを実施し、稼働確認。③ アップデート作業のスケジュールを社内外の関係者と調整し、業務への影響を最小化。④ ベンダーと連携し、将来の脆弱性情報を定期的に受け取り、継続的なセキュリティ管理を実施。
