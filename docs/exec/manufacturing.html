何が起きているか

事業への影響
生産停止により供給遅延、顧客への納期遅れ、売上減少、株価下落。

短期的には代替人員の確保と交渉を進め、長期的には労働環境改善策の策定と従業員コミュニケーションの強化を実施。

2. EU、5か国からの冷間圧延鋼材輸入に対する最終的な広告税を発表

何が起きているか
EUが冷間圧延鋼材に対し、複数国からの輸入に対してアンチダンピング関税を設定。
事業への影響
輸入価格上昇により国内メーカーの競争力が向上、輸入依存度の高い企業はコスト増。
推奨行動
輸入比率を見直し、国内生産・サプライチェーンの強化を図る。また、関税対象外製品の開発や新市場への進出を検討。

3. ポスコエアソリューション、アジアで初めて航空宇宙・防衛分野で使用される高純度レアガスの世界標準認証を取得
